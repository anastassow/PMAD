Section 01 · The Core Differentiator
You Define the Memory Contract
jemalloc has 71 fixed size classes. tcmalloc has ~80 fixed size bands. ptmalloc has dynamic bins you cannot predict. PMAD lets you specify exactly which sizes matter for your workload and exactly how much memory each gets — then guarantees the outcome mathematically.

Configurability + Determinism = Full Predictability

Because PMAD is a pre-allocated slab allocator with a flat O(1) lookup table, you can compute the exact block count, exact usable bytes, and exact per-operation cost for any configuration — before writing a single line of application code.

💡 The Core Insight

jemalloc, tcmalloc, and ptmalloc have fixed internal layouts — you cannot tell them which sizes matter or how much memory each gets. With PMAD you call pmad_init(class_sizes[], percentages[]) and the allocator is shaped exactly around your workload. You know the block count, the overhead, and the latency before running a single line of application code.
